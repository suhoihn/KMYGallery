# Suho Ihn — portfolio

A small, front-end-only React + Vite website with three pages: selected projects, Journey, and the programming Archive. There is no application backend, account system, or deployment configuration.

## Run locally

Install Node.js 22.13 or newer, then from this folder:

```sh
npm install
npm run dev
```

Open http://localhost:5173/. To verify the static site, run `npm run build`; the output is in `dist/`.

## Where things live

- `app/page.tsx` — homepage and selected project data.
- `app/journey/page.tsx` — education and experience timeline.
- `app/archive/page.tsx` — grouped programming history.
- `components/` — header/footer, project cards, back-to-top control, and CSS-driven fireworks.
- `app/globals.css` — all visual styling and animation.
- `public/` — real project screenshots and a compressed Mario gameplay recording.
- `index.html`, `journey/index.html`, and `archive/index.html` — static page entry points.
- `main.tsx` — mounts the right page based on the URL.

The `work/` folder is ignored local research material (including cloned repositories); it is not part of the website. `node_modules/` and `dist/` are generated by npm and Vite. No publishing or Git push is performed by the site itself.
